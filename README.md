# Bristol Regional Food Network Marketplace - Resit Project

## Project Overview
This project is a Django/Django REST Framework and Docker-based digital marketplace for the Bristol Regional Food Network.

## Technologies
- Python
- Django
- Django REST Framework
- Docker
- PostgreSQL or SQLite
- HTML/CSS
